# MuscleUp Gym website

## Before launch
1. script.js, top: set `formEndpoint` (Formspree URL), `gaId`, `pixelId`, and `offer`.
2. Replace `https://www.example.com/` in sitemap.xml and robots.txt with the real domain.
3. Replace stock photos with real ones. Replace logo.png (and icon-192/512.png) with a high-resolution logo.
4. Fill placeholders: prices, trainers, timetable timings, opening hours, reviews, social links.
5. Google Business Profile: claim it, match the name, address and phone exactly.

## Hosting (free)
- Netlify: drag the folder onto app.netlify.com/drop.
- Vercel or GitHub Pages also work. Then connect a domain such as muscleupgym.in.
